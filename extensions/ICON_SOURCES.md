# Bundled plugin icon sources

Every top-level bundled plugin ships one package-local `assets/icon.png`. This ledger records the exact source used for each redistributed or derived asset. Third-party names and marks remain the property of their respective owners and are used to identify the integration.

Plugins without a distinct published mark use the same near-black OpenClaw tile as `lobster`; copy `lobster/assets/icon.png` byte-for-byte when using this fallback. Vendor integrations use the vendor or product mark, including migration sources. A library dependency alone does not change the identity of an OpenClaw feature. Generated brand tiles preserve the identifying mark while normalizing its surrounding presentation to a common rounded plate with enough contrast on both light and dark backgrounds. The runtime never fetches these source URLs. Prefer published square artwork over a generated plate. When a monochrome vendor mark needs a dark plate, use the lobster tile’s near-black #0b0d12, not the former generic navy #111827. Keep official brand-colored backgrounds unchanged.

## September 2026 branding audit

All 159 bundled identity PNGs were inspected for the former generic navy background. The 12 matching tiles were: amazon-bedrock, amazon-bedrock-mantle, codex, github-copilot, groq, llama-cpp, openai, parallel, synthetic, teams-meetings, xai, and zai. Published square artwork replaces the generated plate where sourced above. GitHub Copilot, Parallel, and xAI retain their attributed marks with only the plate and its antialiased edge blends changed to #0b0d12; llama.cpp uses its official white mark on the same near-black. Brand-blue artwork such as Discord, Mattermost, and Signal is intentionally unchanged.

The current first-party OpenAI extension publishes the white Blossom on black; this is not claimed to be a distinct Codex-only logo. Kimi Code and the Moonshot API currently share Kimi branding, so both use the same official application icon rather than inventing a separate API mark. The NVIDIA logo retains both the green eye and the wordmark. Slack’s old PNG included a transparent macOS-tile inset; its replacement has a full white plate and the official mark, without changing shared UI padding.
